Campus Bite

Campus Bite is a web-based nutrition tracking and meal recommendation application designed specifically for college students. It helps users track their daily macronutrient intake, view their hostel mess menus, and discover personalized meal recommendations based on their health and fitness goals.
Features

    Comprehensive Nutrition Tracker:
        Tracks Calories, Protein, Carbohydrates, and Fats against personalized daily targets.
        Interactive progress bars show real-time macro updates as meals are added.
        Log and unlog meals effortlessly.

    ** Hostel Mess Menu Integration:**
        View full weekly meal schedules (Breakfast, Lunch, Snacks, Dinner) for each day of the week.
        Interactively select specific items directly from the mess menu to add them to your tracker.

    ** Smart Recommendation Engine:**
        Custom rule-based algorithm that ranks foods based on user goals (Bulk, Cut, or Maintain) without needing external API dependencies.
        Considers dietary preferences (e.g., Vegetarian) and financial budget constraints.

    ** Personalization & Profiles:**
        Create profiles with specific daily macronutrient targets and calorie limits.

Tech Stack

    Frontend: React (via Standalone Babel in HTML), HTML5, CSS3
    Data Persistence: LocalStorage API, MySQL
    Design: Custom Responsive CSS (Mobile & Desktop friendly)

Quick Start

Since this is a single-file application, no complex installation or node module downloads are required!
